Welcome to **Rythm** — synthetic API monitoring and deployment validation in one console.

Use Rythm to define multi-step API checks, schedule them against your applications, catch regressions before and after releases, and investigate failures with run history and alerts.

## Console areas

| Area | What you do there |
|------|-------------------|
| Dashboard | Health overview across applications and monitors |
| Applications | Group monitors by product or CAR |
| Monitors | Build, test, publish, and schedule checks |
| Deployments | Run release validation workflows |
| Alerts | Triage open incidents |
| Secrets | Manage encrypted values used in monitors |
| ELF Queries | Reusable log search definitions for deployment gates |
| Settings | Notifications, certificates, and ELF proxy configuration |
