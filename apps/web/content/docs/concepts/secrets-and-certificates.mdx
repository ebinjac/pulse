---
title: Secrets and certificates
description: Encrypted values and mTLS profiles used by monitors.
---

Monitors should never store raw passwords or tokens in step configuration. Instead, Rythm uses **secret references** — named aliases whose values are encrypted at rest.

## Secret references

- Created in **Secrets**
- Referenced in monitor steps by alias
- **Masked** in run output and builder previews where possible
- Can be **tested** from the secrets UI before use in production monitors

## Certificate profiles

Some APIs require mutual TLS. **Certificate profiles** in **Settings** bind host, port, and certificate material (PEM or PFX via secret aliases) so monitors can present the correct client certificate.

See [Managing secrets](/docs/guides/managing-secrets) and [Certificate profiles](/docs/guides/certificate-profiles).

<Callout type="warn">
  Secret values cannot be viewed after save — only replaced. Store a backup according to your team’s key management policy.
</Callout>
